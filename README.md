# My Momo Project - Mobile Money Expense
Tracker
Author: George Opoku Mensah
## About
This project analyzes my personal Mobile Money (MoMo) transactions using Python.
## Tools Used
- Python, Pandas, Matplotlib, Google Colab, GitHub
## What I Did
1. Loaded MoMo transaction data
2. Cleaned and grouped by type (Cash
Out, Airtime, Transfer)
3. Calculated total: GHS 360
4. Created bar chart visualization
## Insights
- Highest: Cash Out (200)
- Lowest: Airtime (10)
